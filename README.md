## Projects

### [Complaint Triage System](https://github.com/s17anushka/complaint-triage-system)
A full-stack web app that receives user complaints, uses an LLM (Groq API) to classify urgency and category, and routes them to an admin dashboard with JWT-protected routes.

**Stack:** FastAPI · Vue.js · SQLite · SQLAlchemy · Groq API · SendGrid · JWT  
**What I learned:** How to structure a REST API with proper auth middleware, why separation between public and protected routes matters, and how to integrate third-party APIs without leaking credentials.

---

### [UttarCheck](https://github.com/s17anushka/UttarCheck)
Handwritten answer sheet evaluator using Gemma 4. Accepts scanned answer sheets, scores them, and returns feedback in Hindi and English.

**Stack:** Python · Gemma 4 · OCR  
**What I learned:** How multimodal models handle unstructured input, the tradeoffs between accuracy and latency when using vision-language models, and how to design around model limitations.

---

### [Plume](https://github.com/s17anushka/Plume)
Conversational AI web app with an agent-based backend designed for context retention across sessions, built on a serverless cloud architecture.

**Stack:** Python · Serverless · Agent architecture  
**What I learned:** How stateless compute environments handle session state, why agent memory is harder than it looks, and the operational tradeoffs of serverless backends.

---

### [Posture Detection System](https://github.com/s17anushka/posture-detection)
Real-time body pose analysis using computer vision. Detects joint angles and flags postural deviation with live feedback.

**Stack:** Python · OpenCV · Pose Estimation  
**What I learned:** How pose estimation pipelines work at a low level, the performance constraints of real-time CV, and how to translate geometric data into actionable output.
